========================================================================
 PROGRAMAS PARA TI-Nspire (CX / CAS)  -  Diseño Estructural
========================================================================
UNIDADES: cargas en kN | dimensiones en m | qadm en kN/m2 | f'c, fy en MPa
  (excepto en COLUMNA: b y h van en MILIMETROS)

COMO CREARLOS:
  1. Menu > Insertar > Editor de programas > Nuevo
  2. Nombre (ej. zapata), Tipo = "Programa"
  3. Se crea solo:  Define zapata()=  ...  EndPrgm  -> escribes el cuerpo
  4. Guardar/almacenar: ctrl+B (Store).  Para correrlo: en una calc escribe zapata()

NOTAS DE SINTAXIS:
  :=  es asignar (tecla ctrl + variable, o escribe ":=")
  ≤   es "menor o igual" (ctrl + = , o paleta de símbolos)
  Request "texto",var   -> pide un dato
  when(cond, siVerdad, siFalso)  -> condicional en una linea
  Listas: se escriben con llaves, ej. {1530,1136,1530} ; se indexan con la[1], la[2]...
  NO uses e ni i como variables (son constantes de Euler e imaginario en Nspire)


========================================================================
 PROGRAMA 1:  zapata()   (zapata cuadrada)
========================================================================
Define zapata()=
Prgm
  Request "PD",d
  Request "PL",v
  Request "qadm",q
  Request "lado col c(m)",c
  Request "f'c",f
  Request "fy",y
  d+v→p
  p/q→a
  √(a)→b
  Disp "B (m)=",b
  1.2*d+1.6*v→u
  u/b^2→w
  Disp "Pu=",u
  Disp "qu=",w
  Request "h (m)",h
  h-0.09→g
  4*(c+g)→o
  u-w*(c+g)^2→s
  0.75*0.33*√(f)*(1000*o)*(1000*g)/1000→k
  Disp "Vu punz=",s
  Disp "fiVc=",k
  (b-c)/2→l
  w*b*l^2/2→m
  Disp "Mu=",m
  1000000*m/(0.9*(1000*b)*(1000*g)^2)→rn
  0.85*f/y*(1-√(1-2*rn/(0.85*f)))→ro
  ro*(1000*b)*(1000*g)→x
  0.0018*(1000*b)*(1000*h)→n
  max(x,n)→x
  Disp "As mm2=",x
EndPrgm

  Prueba: 1700,500,180,0.40,21,420, h=0.70 -> B=3.5, qu=231.8,
          Vu=2604 < fiVc=2795, As=4410


========================================================================
 PROGRAMA 2:  columna()   (un punto Pn-Mn del diagrama de interaccion)
========================================================================
Define columna()=
Prgm
  Request "b mm",b
  Request "h mm",h
  Request "f'c",f
  Request "fy",y
  when(f≤28,0.85,max(0.65,0.85-0.05*(f-28)/7))→be
  Request "lista As {..}",la
  Request "lista d {..}",ld
  Request "c (mm)",c
  min(be*c,h)→aa
  0.85*f*aa*b→cc
  cc→p
  cc*(h/2-aa/2)→m
  For w,1,dim(la)
    0.003*(c-ld[w])/c→es
    max(-y,min(y,200000*es))→s
    when(ld[w]<aa,la[w]*(s-0.85*f),la[w]*s)→t
    p+t→p
    m+t*(h/2-ld[w])→m
  EndFor
  Disp "Pn kN=",p/1000
  Disp "Mn kNm=",m/1000000
EndPrgm

  Como usarlo (400x600, 3 capas):
    b=400, h=600, f'c=21, fy=420
    lista As = {1530,1136,1530}
    lista d  = {60,300,540}
    c=318  ->  Pn=1943 kN , Mn=620 kNm   (balanceado)
  Trucos:
    Compresion pura:  c=100000  (da Po, Mn=0)
    Balanceado:       c = 0.003/(0.003+fy/200000)*dmax  (dmax = ultima capa)
    Flexion pura:     prueba c hasta que Pn=0


========================================================================
 PROGRAMA 3:  magnif()   (esbeltez y magnificacion de momentos)
========================================================================
Define magnif()=
Prgm
  Request "Pu",u
  Request "M1",a
  Request "M2",b
  Request "lu m",l
  Request "k",k
  Request "f'c",f
  Request "h m",h
  Request "b m",w
  Request "beta_dns",s
  0.3*h→r
  k*l/r→sl
  Disp "klu/r=",sl
  0.6+0.4*(a/b)→cm
  Disp "Cm=",cm
  4700*√(f)→ec
  (1000*w)*(1000*h)^3/12→ig
  0.4*ec*ig/(1+s)→j
  π^2*j/(1000*k*l)^2/1000→pc
  Disp "Pc kN=",pc
  cm/(1-u/(0.75*pc))→n
  max(n,1)→n
  Disp "dns=",n
  Disp "Mc=",n*b
EndPrgm

  Prueba: Pu=1450,M1=40,M2=130,lu=4.8,k=1.2,f'c=35,h=0.45,b=0.45,bdns=0.60
     -> klu/r=42.7, Cm=0.723, Pc=7066, dns=1.0, Mc=130


========================================================================
 RECORDATORIOS
========================================================================
- zapata y magnif: dimensiones en METROS.  columna: b y h en MILIMETROS.
- d = h - 0.09 en zapatas (cambia el 0.09 si tu recubrimiento es otro).
- beta1: el PROG columna lo ajusta solo (0.85 si f'c<=28).
- Revisa que en el parcial PERMITAN calculadora programable / modo examen.
