========================================================================
 PARTE 1 - COMO CREAR Y METER UN PROGRAMA (paso a paso)
========================================================================
1. Enciende la Nspire. En Inicio (tecla con la casita) -> "Nuevo documento".
   (Debe ser un DOCUMENTO, no el Scratchpad, para poder guardar programas.)

2. Elige "Agregar Calculadora".

3. Abre el editor:  menu  ->  9: Funciones y programas  ->  1: Editor de
   programas  ->  1: Nuevo

4. En el cuadro:
      Nombre:  zapata   (o columna, o magnif)
      Tipo:    Programa
      Acceso a biblioteca: Ninguno
   Presiona OK / Enter.

5. La calculadora YA ESCRIBE sola estas 3 lineas:
      Define zapata()=
      Prgm
      EndPrgm
   >>> TU SOLO escribes el CUERPO entre "Prgm" y "EndPrgm".
   >>> NO vuelvas a escribir Define / Prgm / EndPrgm (si lo repites, NO guarda).

6. Escribe el cuerpo (ver PARTE 3). Baja de linea con Enter.

7. GUARDAR:  menu -> "Verificar sintaxis y almacenar" -> "Almacenar"
   (o el atajo  ctrl + B).
   - Si esta bien: dice "almacenado con exito".
   - Si hay error: te lleva a la linea mala y muestra el mensaje abajo.

8. CORRERLO: agrega una pagina de Calculadora (ctrl + doc -> Calculadora,
   o ctrl + flecha para ir a una pagina de calc). Escribe:  zapata()  y Enter.
   Te ira pidiendo los datos uno por uno.


========================================================================
 PARTE 2 - COMO ESCRIBIR LOS SIMBOLOS
========================================================================
  :=   asignar. Escribe dos puntos y luego igual ( : entonces = ).
       (tambien sirve la tecla sto-> , hace lo mismo)
  ^    potencia: tecla ^ .  Ej. b^2 ,  a^0.5 (que es la raiz cuadrada)
  *    multiplicar SIEMPRE explicito. Ej. 1.2*d  (no 1.2d)
  Request , Disp , For , EndFor  -> con mayuscula inicial como se ve.
       (salen en menu -> I/O  y  menu -> Control, o los escribes)
  when( , max( , min( , dim(  -> en minuscula.
  Listas: se escriben con llaves  {..}  y se indexan con corchetes  la[1]
  pi:  usa la tecla del simbolo pi (o escribe 3.14159265)


========================================================================
 PARTE 3 - LOS 3 PROGRAMAS  (escribe SOLO esto entre Prgm y EndPrgm)
========================================================================

------------------------  PROGRAMA:  zapata  ------------------------
Request "PD",d
Request "PL",v
Request "qadm",q
Request "lado c(m)",c
Request "fc",f
Request "fy",y
p:=d+v
a:=p/q
b:=a^0.5
Disp "B=",b
u:=1.2*d+1.6*v
w:=u/b^2
Disp "Pu=",u
Disp "qu=",w
Request "h(m)",h
g:=h-0.09
o:=4*(c+g)
s:=u-w*(c+g)^2
k:=0.75*0.33*f^0.5*(1000*o)*(1000*g)/1000
Disp "Vu=",s
Disp "fiVc=",k
l:=(b-c)/2
m:=w*b*l^2/2
Disp "Mu=",m
rn:=1000000*m/(0.9*(1000*b)*(1000*g)^2)
ro:=0.85*f/y*(1-(1-2*rn/(0.85*f))^0.5)
x:=ro*(1000*b)*(1000*g)
nn:=0.0018*(1000*b)*(1000*h)
x:=max(x,nn)
Disp "As=",x

   PRUEBA: 1700,500,180,0.40,21,420, h=0.70
   -> B=3.5, qu=231.8, Vu=2604 < fiVc=2795, As=4410


------------------------  PROGRAMA:  columna  ------------------------
Request "b mm",b
Request "h mm",h
Request "fc",f
Request "fy",y
when(f>28,max(0.65,0.85-0.05*(f-28)/7),0.85)→be
Request "lista As {..}",la
Request "lista d {..}",ld
Request "c mm",c
min(be*c,h)→aa
0.85*f*aa*b→cc
cc→p
cc*(h/2-aa/2)→m
For w,1,dim(la)
0.003*(c-ld[w])/c→es
max(-y,min(y,200000*es))→s
when(ld[w]<aa,la[w]*(s-0.85*f),la[w]*s)→t
p+t→p
m+t*(h/2-ld[w])→m
EndFor
Disp "Pn kN=",p/1000
Disp "Mn kNm=",m/1000000

   (aqui uso -> que es la tecla sto->, o cambia cada -> por := )
   PRUEBA: b=400, h=600, fc=21, fy=420
     lista As = {1530,1136,1530}
     lista d  = {60,300,540}
     c=318  ->  Pn=1943 , Mn=620   (balanceado)
   Trucos: c=100000 da Po ; flexion pura: prueba c hasta Pn=0


------------------------  PROGRAMA:  magnif  ------------------------
Request "Pu",u
Request "M1",a
Request "M2",b
Request "lu m",l
Request "k",k
Request "fc",f
Request "h m",h
Request "b m",w
Request "bdns",s
r:=0.3*h
sl:=k*l/r
Disp "klu/r=",sl
cm:=0.6+0.4*(a/b)
Disp "Cm=",cm
ec:=4700*f^0.5
ig:=(1000*w)*(1000*h)^3/12
j:=0.4*ec*ig/(1+s)
pc:=(3.14159265)^2*j/(1000*k*l)^2/1000
Disp "Pc=",pc
n:=cm/(1-u/(0.75*pc))
n:=max(n,1)
Disp "dns=",n
Disp "Mc=",n*b

   PRUEBA: 1450,40,130,4.8,1.2,35,0.45,0.45,0.60
   -> klu/r=42.7, Cm=0.723, Pc=7066, dns=1.0, Mc=130

========================================================================
 PARTE 5 - SI NO TE DEJA GUARDAR (error)
========================================================================
Causa 1 (la mas comun): repetiste Define/Prgm/EndPrgm. Borralas, deja solo el cuerpo.
Causa 2: escribiste la flecha o el <= como texto. Usa := y > (en el when).
Causa 3: falto un * en una multiplicacion, o un parentesis sin cerrar.
Causa 4: usaste e o i como variable (son constantes en Nspire). No las uses.
La Nspire te resalta la linea del error al intentar guardar -> revisa esa linea.
